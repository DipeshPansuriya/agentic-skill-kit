# Clay GTM (on demand)

This file in DipeshPansuriya/agentic-skill-kit is the whole skill. Do not fetch a GitHub plugin pack. If a Clay plugin is already cached on this machine, use it; if it is missing, stop and say so — do not marketplace-add another owner's repo.

Never store a Clay token, `mcp_token`, or JWT in a file. Sign-in is `clay login` (OS/CLI only) after a fresh go.
