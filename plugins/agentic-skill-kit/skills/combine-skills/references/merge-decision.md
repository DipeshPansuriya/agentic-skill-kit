# Merge Decision Score (0–12)

Score each criterion 0, 1 or 2.

| # | Criterion | 0 | 1 | 2 |
|---|---|---|---|---|
| 1 | **Same domain** | Unrelated topics | Adjacent | Same domain/team |
| 2 | **Shared rules** (see inventory overlap) | < 10% overlap | 10–30% | > 30% |
| 3 | **Shared output style** | Different formats | Partly similar | Same format/tone/labels |
| 4 | **Used together** | Never in one request | Sometimes | Often chained |
| 5 | **One-sentence description possible** | No | With effort | Easily |
| 6 | **Trigger conflict today** (skills compete) | Never | Occasionally | Often |

**Decision:** ≥ 8 merge · 5–7 partial merge / house-rules skill · ≤ 4 keep separate.

## Alternatives to a full merge
| Option | When |
|---|---|
| **House-rules skill:** one small skill with shared rules only, the others reference it | Rules overlap but tasks differ |
| **Partial merge:** merge the 2 closest, keep the rest | One skill is an outlier |
| **Sharper descriptions:** keep separate, fix triggers | Only problem is skills competing |
